# Images

Drop the four generated images here. The landing page picks them up
automatically and shows a labelled placeholder until each one exists.

    hero.webp        Hero — the level beam
    asymmetry.webp   The asymmetry — crushed pan
    enclave.webp     The sealed verdict — wired shut
    clock.webp       The clock — ninety bars

The prompts are in `docs/image-prompts.md`.

WebP keeps these small; PNG or JPG work too if you rename the file extension
in `index.html`. Aim for under about 400 KB each so the page stays quick on
venue wifi.
